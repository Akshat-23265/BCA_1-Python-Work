## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Python 3.x](https://www.python.org/downloads/)
- [Jupyter Notebook](https://jupyter.org/install) or [VS Code](https://code.visualstudio.com/) with the Jupyter extension

### Running the Notebooks

1. **Clone the repository**
   ```bash
   git clone https://github.com/Akshat-23265/BCA_1-Python-Work.git
   cd BCA_1-Python-Work
   ```

2. **Launch Jupyter Notebook**
   ```bash
   jupyter notebook
   ```

3. Open any `Experiment X.ipynb` file from the browser interface and run the cells.
